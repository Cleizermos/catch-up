# Catch Up

Crie um app que catalogue objetos diversos.
Imagine uma gincana, onde um apresentador pede um objeto e a equipe tem 1 minuto para achar entre milhares de objetos misturados emvárias barracas espalhadas entre uma rua.
A ideia é catalogar os objetos, para encontrar o mais rápido possível.
Pensei em um aplicativo web para que todos os componentes da equipe possa pesquisar por voz e rapidamente e saber onde está o objeto.
tem que ser um app leve e certeiro.
Se tiver alguma sugestão do que podemos fazer para fazer isso de form eficaz, me avise
